# Pre-Work Requirements

Before any task:
1. Read the project MAP, `docs/forLLMConsumption.md` (≤ 40,000 bytes: purpose, architecture in
   brief, where things are, the invariants a change must respect, how to run/test/deploy, pointers
   to topic docs). Follow its pointers ONLY for the areas you touch.
2. Grep `docs/lessons-learned.md` and `docs/findings-ledger.md` for the component you touch. Never
   read them whole, and never read `docs/archive/` unless a pointer sends you there.
3. Read the code you will change — the product file, not its installed copy
   (`project-specific.md`); flag conflicts with the design before coding.
